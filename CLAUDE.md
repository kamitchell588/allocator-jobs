# Allocator Jobs — CLAUDE.md

## What this project is
A job board for institutional allocator roles (endowments, pensions, family offices, sovereign wealth) built for FRAM Partners. Scrapes job data, filters it, and publishes a static HTML dashboard.

## Architecture
- **`scraper.py`** — main script, run via `bash run.sh`
- **`dashboard.html`** — public-facing job board (regenerated by scraper)
- **`admin.html`** — internal admin view with hide/unhide buttons (password: `fram2024`)
- **`allocator_jobs.csv`** — intermediate CSV used as historical job cache
- **`hidden_jobs.txt`** — newline-separated list of URLs suppressed from public dashboard. Hiding is a status (`status` column in the CSV), not a deletion: remove the URL to bring the job back.
- **`.env`** — `APIFY_TOKEN` and `GH_TOKEN` (never committed)

## Where things are edited (master files)
| What | File | Notes |
|---|---|---|
| Firms | `data/orgs.csv` | One row per firm. `search_term` = what Apify searches; `aliases` = other names (separate with `|`); `domain` locks the firm to its website; `active` Y/N = wanted in the generated Apify tasks (N = tracked, not searched); `old_task` = firm is already in one of the older hand-built tasks (the generator skips it until you clear this). |
| Titles to keep | `data/title_include.txt` | Substring match. |
| Titles to drop | `data/title_exclude.txt` | Substring match; a leading `=` (e.g. `=hr`) means whole word only. |
| Look-alike companies to reject | `data/exclude_companies.txt` | Matched anywhere in the company name; also purges history. |
| Hand-set sector | `data/sector_overrides.csv` | |
| Location filter (metros) | `data/metros.csv` | city + state -> metro. Unlisted places show as Other US / Other Canada. |
| Hidden jobs | `hidden_jobs.txt` | Admin Hide button writes this. |
| Manual jobs | Google Sheet | Expire 60 days after first seen. |
| Apify task groups | `data/task_groups.csv` | sector -> task group. Tasks are generated, not hand-edited: Actions tab -> "Sync Apify tasks" (dry run unless "apply" is ticked; "only" = one task, "schedule" = add the daily schedule). Creates/updates only tasks named `fram-*`. |
Apify tasks are an input, not a master: their firm lists and exclusions should come from the files above. Snapshot of the older tasks' inputs (as of 2026-11-19): `apify/archive/current_tasks_2026-11-19.json`.
Tests: `python tests/test_master.py` (firm list + filter files), `python tests/test_sync.py` (task generator, against a fake Apify).

## Filtering pipeline
1. **Layer 2** — title must match a phrase in `data/title_include.txt` (investment, portfolio, analyst, etc.)
2. **Exclusions** — title must NOT match a phrase in `data/title_exclude.txt` (receptionist, compliance, etc.)
   Both files: one phrase per line, `#` comments. Edit them directly; the run stops if either is empty.
3. **Geo** — US or Canada only
- Manual Google Sheet entries bypass all filters (pre-vetted)

## Data sources
1. Apify datasets (all IDs in `DATASET_IDS`) — fetches last 7 days, merges with CSV history
2. Supplemental scrapers — NCPERS, AllocatorJobs.com, CFA Institute, Council on Foundations, UTIMCO
3. Manual Google Sheet — pre-vetted jobs added manually

## Safety checks
- **Dedup** is on the job link; only a job with no link falls back to title + company + location.
- **Shrink guard**: if a run would cut the public board by more than 30% vs the last saved CSV, it stops (exit 1), writes nothing, and the workflow skips the commit. For an intended drop: `ALLOW_SHRINK=1 bash run.sh`.
- **Tests** (no network): `python tests/test_step1.py`. Comparison against a saved baseline: `python tests/run_pipeline.py <dir>` then `python tests/compare.py <baseline> <dir>`.
- **Manual / supplemental jobs expire 60 days after first seen** (`status=expired`: kept in the CSV so the clock isn't reset while the Google Sheet still lists the row, but off the public board and admin). Delete the row from the sheet to remove it entirely. Tests: `python tests/test_expiry.py`.
- Old Apify task inputs are kept in `apify/archive/` for reference only.
